# Nirvancare

## Overview

The **NirvanCare** is a centralized database designed to store and manage patient records securely. This system allows authorized personnel to access patient data efficiently, ensuring smooth medical operations and seamless data sharing across healthcare providers.

## Features

- Centralized patient data storage
- Secure access control for authorized personnel
- Easy retrieval and update of patient records
- Scalable and efficient database management

## Technology Stack

- **Backend**: Node.js
- **Database**: MongoDB 
- **Frontend**: HTML

## Security & Compliance

- **Data Encryption**: All sensitive patient data is encrypted at rest and in transit.
- **Access Control**: Role-based access ensures only authorized personnel can view or modify data.
- **Compliance**: Follows HIPAA and GDPR regulations to protect patient privacy.

## Usage

1. **Register/Login**: Users must authenticate before accessing the system.
2. **Patient Record Management**: Add, edit, and retrieve patient details.
3. **Search & Filter**: Easily search patient records using various filters.
